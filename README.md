# 便利商店物語

一款可以在手機瀏覽器遊玩、支援離線的 3D 便利商店經營模擬遊戲（原創作品）。

看著顧客自己走進店裡、挑選商品、排隊結帳；店員會收銀、補貨、打掃；貨架會隨著銷售慢慢變空。
從一間街角小店開始，擴建店面、開設分店，最後成為連鎖企業。

## 怎麼玩

- **鏡頭**：單指拖曳移動、兩指旋轉與縮放；電腦上左鍵拖曳移動、右鍵旋轉、滾輪縮放。也可以按左側的 ⟲ ⟳ ◎。
- **時間**：右上角 ❚❚ ▶ ▶▶ ▶▶▶ 可以暫停或切換 ×1 / ×2 / ×3。
- **點顧客**：看他的類型、心情、購物籃。
- **點貨架**：看庫存、切換擺放類別。
- **商品**：調整售價（影響購買意願與滿意度）。
- **進貨**：向批發商（便宜、隔天到）或物流（貴、2 小時到）叫貨。鮮食與熱食會過期。
- **擺設**：自由購買、移動、旋轉、出售貨架、冰箱、收銀台、熱食櫃、咖啡機、盆栽、桌椅。
- **員工**：雇用店員或店長、安排早班／晚班／全天。員工會累積經驗升級。店長每晚會自動叫貨。
- **擴張**：擴建店面（4 個等級）、升級招牌／燈光／地板、開設分店。

每天 24:00 結算薪水與租金，並顯示當日報表與明日天氣、活動。

## 安裝到手機（離線遊玩）

開啟遊戲網址後：

- **iPhone**：Safari → 分享 → 「加入主畫面」
- **Android**：Chrome 選單 → 「安裝應用程式」

安裝後沒有網路也能玩。進度存在手機上，可在「系統」複製存檔碼備份或搬到其他裝置。

## 開發

純 HTML/CSS/JavaScript（ES Modules），不需要建置步驟。Three.js 0.170 放在 `vendor/`。

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

| 檔案 | 內容 |
| --- | --- |
| `js/data.js` | 商品、設備、顧客類型、店面等級、任務等遊戲資料 |
| `js/state.js` | 遊戲狀態、存檔／讀檔、庫存計算 |
| `js/path.js` | 格子地圖與 A* 尋路 |
| `js/world.js` | Three.js 場景、店面與人物模型、日夜變化 |
| `js/sim.js` | 時間、顧客 AI、店員 AI、經濟與事件 |
| `js/ui.js` | HUD、面板、對話泡泡、日報 |
| `js/build.js` | 擺設模式 |
| `sw.js` | 離線快取（改版時請更新 `VERSION`） |
